# ポイント定義

## trkpt（トラックポイント）
- ルート上に約50m置きに配置されたルートの構成点
- 交差点付近など必要な箇所では密度が上がる
- trkpt 列はルートの形状そのものを表す

## wpt（ウェイポイント）
- ナビゲーションアプリで Turn-by-Turn 案内を行うための案内点（主に交差点）
- ターン角度に応じて左折・やや左・直進維持・やや右・右折などのアイコン・音声案内が変わる
- スタート・ゴールは wpt かつ acpt
- ユーザーが任意の trkpt を wpt に指定できる
- wpt の名称はユーザーが変更できる
- wpt は必ずいずれかの trkpt に一致する

## acpt（アンカーポイント）
- ルートを引く際にユーザーが指定するコントロールポイント
- trkpt 列は必ず acpt を通るルートとなる
- スタート・ゴールは acpt かつ wpt
- ユーザーがドラッグ操作で動かせるのは acpt のみ
- acpt は必ずいずれかの trkpt に一致する

## 地図クリック時の挙動

### 既存 trkpt に近い場合（20m 以内）
- 最近傍の trkpt を選択し、ダイアログを表示
- ユーザーが以下から選択する：
  - 「wpt にする」：その trkpt を案内点として前後の wpt の間に挿入
  - 「acpt にする」：その trkpt をコントロールポイントとして前後の acpt の間に挿入
  - 「ゴールを延伸する」：近傍 trkpt を無視し、クリック地点を新ゴールとして延伸（往復路など trkpt が重なる場合の対策）
  - 「キャンセル」：何もしない

### 既存 trkpt から離れている場合（20m より遠い）
- クリック位置を新しい wpt かつ acpt とする（新ゴール）
- 旧ゴール地点は acpt のみとなる（wpt にはしない）
- 旧ゴール〜新クリック地点間のルートを検索し trkpt を生成する

## wpt 自動検出の方針

- GPX ファイル読み込み時：detect_turns を自動実行し、wpt を設定する
- ルート変更操作（ゴール延伸・acpt ドラッグ・追加・削除）：detect_turns は実行しない
- ユーザーが「wpt 検出」ボタンを押したとき：detect_turns + 交差点名取得を実行する

## route_modified フラグ

| 操作 | フラグ |
|---|---|
| GPX 読み込み（detect_turns 自動実行後） | False |
| ゴール延伸 | True |
| acpt ドラッグ・追加・削除 | True |
| 「wpt 検出」ボタン押下 | False |

- 「強化GPX生成」ボタン押下時、フラグが True なら警告ダイアログを表示する
- 警告：「ナビ案内点がルートと一致していない可能性があります」→ [続行] [キャンセル]
