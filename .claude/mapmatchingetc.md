マップマッチング、標高補正、WPT検出、TRKPTの間引き

## 入力GPXの種別

このアプリに入力される可能性があるGPXファイルの特徴：

| 種別 | 説明 | trkpt密度 | マップマッチング | wpt |
|------|------|-----------|----------------|-----|
| 1. 新規作成 | アプリ内で新規作成 | OSRM由来 | 不要 | なし |
| 2. ルートデータ | Stravaなどで作成したルート | それなりに広い | 済み | なし |
| 3. ルートデータ（wptあり） | 本アプリで出力した強化GPX等 | それなりに広い | 済み | あり |
| 4. 実走行データ | GPSデバイス・Stravaの実走記録 | 密（未マッチング） | 未 | なし |

種別2と4はファイル内容だけでは自動判別できないため、ユーザーが選択する：

> **ファイルアップローダーの上側に「□ 実走行データ（マップマッチング・間引きを行う）」チェックボックスを設置**
> デフォルトはオフ（ルートデータ扱い）

- チェックなし → 種別2または3として処理
- チェックあり → 種別4として処理。**GPX内のwptは無視し、detect_turns＋交差点名取得で再検出する**

---

## 出力したい強化GPX

- a. trkpt間隔はそれなりに広い（目標：50m平均程度）
- b. マップマッチング済み
- c. wptがちゃんと入っている

## 種別ごとの処理

| 処理 | 1. 新規作成 | 2. ルートデータ | 3. ルートデータ(wptあり) | 4. 実走行データ |
|------|:-----------:|:---------------:|:------------------------:|:---------------:|
| マップマッチング | なし | なし | なし | **あり** |
| TRKPTの間引き（RDP） | なし | なし | なし | **あり** |
| スパイク補正 | なし | あり | あり | あり |
| WPT検出＋交差点名取得 | なし（手動ボタン） | **あり（自動）** | なし（ファイルのwptを使用） | **あり（自動）** |
| 標高補正（GSI） | 手動ボタン | 手動ボタン | 手動ボタン | 手動ボタン |

※ 種別1はmakeroute.mdの仕様のまま（何もしない、手動でwpt検出可能）
※ マップマッチングが必要なのは種別4のみ。手動実行は不要

## マップマッチング（種別4のみ）

- Valhalla `/trace_attributes` を使用
- 処理順序：**Map match → RDP間引き**（逆順は不可：間引き後では交差点を見逃す可能性がある）
- Map match後にRDP間引きをすることで、道路形状を保ちながら適切な密度に収束する

---

## TRKPTの間引き（種別4のみ）

**Ramer-Douglas-Peucker（RDP法）**

- 直線区間 → 大胆に間引く
- カーブ・交差点付近 → 形状を保つため間引かない
- `epsilon`（許容誤差）を距離で指定：5〜10m
- 50m平均はあくまで目標値であり、保証は不要

```python
from rdp import rdp
thinned = rdp(points, epsilon=5.0)  # 5m許容
```

## 標高補正（全種別共通・手動）

**現行からの変更点：**
- 従来：ファイル読み込み時に自動実行（画面上部に標高データ選択UIを表示）
- 新仕様：**「強化GPXの出力」セクションに移動し、手動ボタンで実行**

**UI：**
- 「強化GPXの出力」セクションに「⛰️ 国土地理院で標高補正」ボタンを追加
- ボタン押下 → GSI標高取得＋スパイク補正を実行
- 実行完了後のみ「GSI補正データ」の選択が可能になる
- 未実行の場合は「元データ（スパイク補正済み）」のみ選択可能

**標高データ選択ラジオボタンの表示形式：**

GSI補正前：
- 元データに「★推奨」を付ける
- GSIオプションは「国土地理院補正（実施前）」と表示し選択不可扱いにする
  - Streamlit の `st.radio` は個別選択肢のdisableが不可のため、
    「実施前」を選択した場合は強制的に元データに戻す処理で代替する

GSI補正後：
- 勾配の絶対値合計（上り + |下り|）が小さい方に「★推奨」を付ける

表示例（GSI補正前）：
  ● 元データ（スパイク補正済み）　★推奨　上り +1.3%  下り -1.5%
  ○ 国土地理院補正（実施前）　　　　　　　　　　　　← 選択しても元データに強制戻し

表示例（GSI補正後・GSI推奨）：
  ○ 元データ（スパイク補正済み）　上り +1.3%  下り -1.5%
  ● 国土地理院補正（スパイク補正済み）　★推奨　上り +0.9%  下り -1.0%

**対象範囲：**
- 実行時点の全trkpt（active_points）に対して標高を取得
- ルート延伸・acptドラッグ後に再実行すれば新しい区間にも適用される
- 新規作成ルートにも対応（「元データ」は存在しないため、GSI補正のみ）

**標高データなし・未補正での出力警告：**
- 元データに標高がなく（`_grade_org` が None）、かつGSI補正が未実施の場合、
  「強化GPXを生成」ボタン押下時に以下の警告ダイアログを表示する
  - メッセージ：「標高データがありません。国土地理院で標高補正してから出力することをお勧めします。」
  - [⛰️ 補正してから生成] → 標高補正を実行してから生成へ進む
  - [📥 このまま生成] → 標高なしのまま生成する

**GSI補正完了後の自動選択：**
- 元データに標高がない場合（`_grade_org` が None）、GSI補正完了時は自動的に
  「国土地理院補正」を選択状態にする（`_elev_choice = "fix"` に設定）
